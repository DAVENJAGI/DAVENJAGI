### 🩺 Currently Building: **Chronicare**

> A smart medical solution for patients with chronic diseases.

- 💊 **Chronicare** is a **cross-platform solution** (Web + Mobile App) that empowers patients to:
  - Book **appointments** with doctors remotely
  - Place **medication orders** from home
  - Receive **real-time notifications** and reminders
  - Easily monitor their vitals, sugar levels, heart rate, body weight, through out their medication period.
- ⚙️ Built using:
  - **Backend**: Flask + Flask-SocketIO

This project emphasizes **remote health monitoring**, data privacy, and accessibility for those managing long-term conditions, as well as working with clinical data for ease of patient health management.

### 🐟 Built: **FarmGuard**

> A smart surveillance and defense system for large-scale fish farming.

- 📷 **FarmGuard** is a **computer vision-powered system** built to:
  - **Detect predators** near fish ponds using realtime camera feeds and ultrasonic sensors
  - Automatically **trigger acoustic deterrents** (e.g., high-frequency sounds) to repulse them
  - Log predator encounters and notify the farmer
- 🧠 Powered by:
  - **Computer Vision** models (trained with TensorFlow)
  - **Ultrasonic sensors** for obstacle proximity detection
  - **Custom electronic circuits** for sensor integration and actuator control (e.g., buzzers and alarms)
  - **Microcontrollers (Arduino)** for real-time signal processing

This system merges **AI, electronics, and automation** to improve fish survival rates in aquaculture.
